# TG-WS-PROXY — Android port (unofficial)

Локальный MTProto-прокси для Telegram прямо на телефоне. Обходит блокировки на мобильной связи через **CloudFlare-проксированные WebSocket домены**.

## Как работает

```
Telegram (тот же телефон)
   ↓ tg://proxy?server=127.0.0.1&port=1443
Прокси (Android Foreground Service)
   ↓ TLS WebSocket → CloudFlare → Telegram DC
интернет
```

Telegram подключается к `127.0.0.1:1443` — это **loopback внутри ядра**, мобильная сеть тут не нужна. Прокси уже сам ходит наружу через CF-домены, которые оператор не блокирует.

## Цепочка fallback

1. **Прямой WS** к `*.web.telegram.org` (на чистых сетях работает напрямую)
2. **CF Worker** — твой Cloudflare Worker, если задан в настройках
3. **CF proxy pool** — пул из ~10 проксированных CF доменов с авто-обновлением, **параллельная гонка** 3 доменов одновременно
4. **TCP fallback** — последний шанс прямого TCP до DC

Это и есть мобильный байпасс. Никакой DPI-фрагментации, фейк-TLS и прочей серверной шелухи — оно бессмысленно для локального loopback-прокси.

## Использование

1. Запустить прокси большой кнопкой на главной (красная → зелёная)
2. **Открыть в Telegram** — Telegram сам подхватит ссылку и предложит включить прокси
3. Можно добавить плитку **TG Proxy** в шторку для быстрого вкл/выкл

## Настройки (вкладка «Настройки»)

- **Порт** / **Secret** / **DC → IP** — стандартные параметры MTProto
- **Размер пула WS** — заранее прогретые соединения для быстрого старта сессий
- **CloudFlare proxy fallback** — главный тумблер мобильного байпасса (вкл по умолчанию)
- **Свой CF домен** — кастомный CF-проксированный домен (опционально)
- **CF Worker домен** — свой Cloudflare Worker, пробуется первым (опционально)

## Технические детали

- AES-256-CTR (как в оригинальном MTProto Proxy)
- Протоколы: abridged / intermediate / padded intermediate
- Foreground Service — переживает свёртывание, не убивается системой
- Quick Settings tile для быстрого вкл/выкл из шторки
- Параллельная гонка CF доменов: дедлайн 5 секунд на пачку из 3, запоминание рабочего домена

## Кредиты

Проект — порт оригинала **[tg-ws-proxy от Flowseal](https://github.com/Flowseal/tg-ws-proxy)** (v1.7.0).
Оригинал на Python, тут переписано на Java для Android.
